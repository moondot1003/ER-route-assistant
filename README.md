# ER-route-assistant

《이터널 리턴》의 장비 제작과 지역별 재료 수급을 돕는 웹 앱입니다. 제작 경로가 낯선 초보 플레이어와 장비 조합을 바꿔 보려는 플레이어를 대상으로 만들었습니다. 목표 장비의 재료를 확인하고, 지역 방문 순서를 정하거나 추천받고, 현재 경로에서 만들 수 있는 장비를 거꾸로 찾아볼 수 있습니다. **비공식·비상업적 대학 과제**이며 게임 운영사와 제휴하거나 승인을 받은 서비스가 아닙니다.

## 실행과 사용

Node.js **20.19 이상 또는 22.12 이상**이 필요합니다. API 키나 환경변수는 필요하지 않습니다.

```bash
npm install
npm run dev
```

터미널에 표시되는 로컬 주소(기본 `http://localhost:5173/`)를 엽니다. 실험체와 무기 유형을 고른 뒤 영웅 장비를 최대 5부위까지 선택합니다. 지도에서 지역을 방문 순서대로 누르거나 추천 경로를 선택하면 재료의 획득 가능 여부가 갱신됩니다. 부족한 재료 타일을 **우클릭**하면 드론 배송 지정량이 1개 늘고, 노란 테두리의 드론 타일을 우클릭하면 1개 줄어듭니다. 지도 옆 드롭다운에서는 현재 경로로 직접 제작할 수 있거나 드론 배송 1회가 필요한 장비를 선택할 수 있습니다.

```bash
npm run test
npm run typecheck
npm run build
```

## 구현 범위와 데이터 출처

- 실험체·지원 무기 유형 선택, 부위별 영웅 장비 선택, 각 영역의 초기화 기능을 구현했습니다. 실험체 A/B는 **가상 시연 데이터**입니다.
- 제작법을 일반 재료까지 재귀적으로 전개합니다. 여러 장비가 공유하는 중간 제작물, 한 번에 여러 개 생산되는 제작법, 이미 보유한 시작 장비를 계산에 반영합니다.
- 선택한 장비의 재료를 기준으로 **최대 3개 지역·드론 배송 1회 이하**인 경로를 추천합니다. 지도에서 지역을 직접 추가·제거하고 방문 순서를 볼 수도 있습니다. 수동 경로에는 지역 수 제한을 두지 않았습니다.
- 재료별 부족량과 드론 배송 지정량을 나누어 표시하며, 지정량과 호출당 획득량으로 호출 횟수를 계산합니다. 지도 옆 장비 후보는 **각 장비를 독립적으로** 평가해 직접 제작 가능/드론 1회 필요로 나눕니다. 후보를 고르면 목표 장비와 재료 계획에 반영됩니다. 이는 실제 드론을 호출하는 기능이 아닙니다.

장비 이름·등급과 제작법은 공개 나무위키 장비 문서 7개 및 재료 문서를 참고해 구조화했습니다. 영웅 장비 84종의 제작 트리를 테스트로 확인했고, `소수`와 `컴포지트 보우` 제작법은 플레이어가 **게임 안에서 직접 확인한 결과**를 우선 적용했습니다. 지역 상자 자료는 사용자가 [공식 12.0 시즌 시작 패치 노트](https://playeternalreturn.com/posts/news/3743?hl=ko-KR)에서 옮긴 **20개 지역·362개 항목의 고정 샘플**입니다. 지역별 수량은 해당 지역 전체 배치량이며 한 플레이어가 얻을 수 있는 수량을 뜻하지 않습니다. 채집 가능 지역과 재료 획득 단위에는 숙련 플레이어가 제공한 규칙을 적용했습니다. 이 자료들은 **현재 패치의 공식 API 응답으로 검증한 실시간 데이터가 아닙니다.**

## 개발 과정

처음에는 가상 실험체 선택과 데이터 접근 구조를 만들었습니다. 이후 장비·중간 재료·제작법을 분리해 저장하고, 영웅 장비의 제작 트리를 검증했습니다. 다음으로 장비 선택과 재귀 재료 계산을 연결했습니다. 지역별 재료 포함 여부를 이용한 경로 추천을 추가한 뒤 지도에서 직접 경로를 편집하도록 바꿨습니다. 마지막에는 드론 배송 지정량을 재료별로 조절하고, 현재 경로에서 제작 가능한 장비를 역탐색하도록 확장했습니다. 이 흐름은 `436ad70`(데이터), `048f628`(재료 계산), `b3d9e50`(경로 추천), `18d848a`(지도), `67d1c87`(드론 지정), `31a2d65`(수량 조절·장비 역탐색) 커밋에서 확인할 수 있습니다.

## 효과적이었던 실천 3가지

1. **기능을 나누고 Git으로 추적했습니다.** 데이터, 계산, 지도, 드론 계획을 단계별로 검증하고 커밋해 변경 원인을 찾기 쉬웠습니다.
2. **AI 결과를 실행해 확인했습니다.** 자동 테스트 외에 사용자가 브라우저 동작을 확인했습니다. 재료 2개가 부족할 때 첫 드론 지정에서 2개 모두 지정되는 문제를 발견해, 1개씩 조절하도록 요구사항을 수정했습니다.
3. **큰 기능을 작은 요청으로 나눴습니다.** 드론 지정과 장비 역탐색을 Phase 5C-1·5C-2로 분리하고, 기존 계산 함수와 테스트를 재사용했습니다.

## 어려움과 대응 3가지

1. **공식 API 키가 아직 없어 실시간 데이터를 연결할 수 없었습니다.** 공개 장비 문서와 사용자가 옮긴 패치 자료를 샘플로 사용하고 출처를 표시했습니다. 패치 최신성 문제는 남아 있습니다.
2. **제작법을 단순 합산하면 수량이 틀릴 수 있었습니다.** 중간 제작물의 공동 수요를 먼저 모으고, 제작 결과 수량에 맞춰 제작 횟수를 올림 계산하며, 시작 장비를 필요할 때만 차감했습니다. 누락·순환 제작법도 오류로 처리합니다.
3. **초기 드론 지정은 재료의 필요량 전체를 한 번에 배정했습니다.** 브라우저 확인 후 재료별 지정 수량으로 상태를 바꾸고 부족 타일과 드론 타일을 분리했습니다. 실제 크레딧 비용 계산은 아직 없습니다.

## Codex CLI 협업 증거

과제 공지의 Claude Code 대신 **담당 교수의 개별 허가를 받아 OpenAI Codex CLI**를 사용했습니다. 아래는 실제 Codex CLI 대화에서 짧게 옮긴 **요청·응답 3건**입니다. 원본 세션 로그 전체와 스크린샷은 저장소에 포함하지 않았습니다. 커밋은 결과물을 확인하는 근거이며 대화 기록 자체는 아닙니다.

1. **제작 재료 계산**
   - 사용자 요청: “장비를 1개만 선택해도 계산 결과를 표시합니다.”
   - Codex 응답: “영웅 장비를 하나만 선택해도 필요 재료가 즉시 표시되며, 선택 변경·해제나 실험체·무기 타입 변경에 따라 다시 계산됩니다.”
   - 결과 확인: `src/domain/craftingCalculator.ts`, 커밋 `048f628`.
2. **경로 추천**
   - 사용자 요청: “방문 지역은 최대 3개, 드론 호출은 총 1회 이하.”
   - Codex 응답: “같은 지역 조합에서는 초반 필요 재료 확보 수량이 가장 높은 방문 순서 하나만 표시합니다.”
   - 결과 확인: `src/domain/routeRecommendations.ts`, 커밋 `b3d9e50`.
3. **드론 배송 수량과 장비 역탐색**
   - 사용자 요청: “부족한 재료 타일을 우클릭하면 드론 배송 지정 수량이 1개 증가합니다.”
   - Codex 응답: “재료별 드론 지정량을 1개씩 늘리거나 줄일 수 있습니다.”
   - 결과 확인: `src/domain/materialPlan.ts`, `src/domain/craftableEquipment.ts`, 커밋 `31a2d65`.

## 검증과 남은 한계

제출 전 `npm run test` **72개 통과**, `npm run typecheck` **통과**, `npm run build` **성공**, `git diff --check` **통과**를 확인했습니다. 사용자는 실험체·장비 선택, 지도 경로 편집, Phase 5C-2의 브라우저 동작을 확인했다고 보고했습니다. 이 문서 작업 중에는 브라우저 수동 검사를 새로 수행하지 않았습니다.

실험체는 A/B 두 가상 예시이고 무기 데이터는 글러브·활·방망이만 지원합니다. 공식 API 연동과 패치별 자동 갱신이 없으므로 데이터의 최신성을 보장할 수 없습니다. 경로 판정은 지역에서 재료를 **얻을 수 있는지**만 보며 실제 상자 수량, 경쟁, 이동 거리·시간, 하이퍼루프를 반영하지 않습니다. 따라서 최적 경로나 실제 제작 성공을 보장하지 않습니다. 상위 랭커 경로, 전설 장비 교체, 장비 능력치 A/B 비교도 구현하지 않았습니다. 게임 및 지도 자산의 권리는 님블뉴런 등 해당 권리자에게 있습니다.

## 채점용 핵심 소스 파일 5개

1. `src/App.tsx` — 실험체·장비·경로·드론 상태를 연결합니다.
2. `src/domain/craftingCalculator.ts` — 제작 트리와 공유 중간 제작물의 수량을 계산합니다.
3. `src/domain/materialPlan.ts` — 경로 포함·부족·드론 지정 재료를 구분합니다.
4. `src/domain/routeRecommendations.ts` — 방문 순서가 있는 추천 경로를 계산합니다.
5. `src/domain/craftableEquipment.ts` — 경로별 제작 가능 장비를 독립적으로 분류합니다.
