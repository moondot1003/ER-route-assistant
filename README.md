# ER-route-assistant

Eternal Return 플레이어를 위한 루트 작성 앱입니다. 현재 화면에서 가상 실험체와 지원 무기 유형을 고르고, 영웅 장비 최대 5개를 선택하면 필요한 일반 재료를 바로 확인할 수 있습니다. 지역 획득 데이터는 이후 기능을 위한 별도 참조 자료로 준비했습니다.

## 실행

Node.js 20.19 이상 또는 22.12 이상이 필요합니다.

```bash
npm install
npm run dev
```

검사: `npm run typecheck`, `npm run test`, `npm run build`.

## 가상 데이터와 출처

출전 설정에 사용하는 샘플 카탈로그의 실험체·시작 장비·지역·재료 수량은 **가상의 학습용 예시**이며 실제 게임 정보가 아닙니다. 장비 선택 목록의 이름·등급은 아래의 장비 문서와 플레이어의 게임 내 확인 결과를 바탕으로 하며, 공식 API로 검증한 현재 패치 목록은 아닙니다. 무기 유형 이름과 시작 Common 무기·Shirt·Sneakers 규칙은 숙련 플레이어가 제공한 프로젝트 요구사항을 바탕으로 합니다. 샘플 카탈로그의 고철 묶음 수치도 시연용이며 별도 지역 자료의 수량 계산에는 적용하지 않습니다. `mock-*` ID는 앱 내부 식별자이며 공식 API 코드가 아닙니다.

가상 지역의 인접 관계, 하이퍼루프 유무, 상자 그룹별 수량은 오직 데이터 구조 시연용입니다. 실제 지역 연결이나 아이템 생성 수량으로 해석해서는 안 됩니다. 공식 API 키 요청은 아직 처리 중입니다.

## 현재 범위와 다음 단계

**구현됨:** `src/data/`의 비동기 저장소 인터페이스를 통해 화면용 샘플 카탈로그를 제공하고, 실험체·지원 무기 유형 선택을 지원합니다. 무기 유형에 맞는 영웅 무기와 부위별 영웅 장비를 선택·해제할 수 있습니다. 실험체나 무기 유형을 바꾸면 장비 선택 5개가 초기화됩니다. 선택한 장비의 직접 제작법을 일반 재료까지 전개하고, 공통 중간 제작물의 수요와 제작 결과 수량을 반영하며, 해당 시작 장비를 차감합니다. 필요한 재료는 획득 방식 정보와 함께 아이콘형 문자 타일로 표시합니다. 지도에서 지역을 순서대로 선택하거나 추천 루트를 적용하면 재료 상태가 갱신됩니다. 추천은 최대 3지역·1드론 후보 중 상위 20개를 보여주며 드론 포함 여부를 필터링할 수 있습니다. 루트 포함·미포함·드론 예정·잉여 재고를 현재 수요와 계획에서 계산하는 순수 함수도 준비했습니다.

**미구현:** 화면용 가상 카탈로그의 제작법 목록은 비어 있고, 별도로 수집한 제작법만 재료 계산에 사용합니다. 재료 우클릭·드론 지정은 연결하지 않았으며, 상자 그룹 평가, 이동 편의 평가, 실제 드론 호출, 전설 장비 교체, 빌드 A/B 비교, 공식 API 연결도 구현하지 않았습니다. 추후 API를 연결할 때는 키가 브라우저에 노출되지 않도록 별도 서버 중계를 사용해야 합니다.

## Phase 2·3 데이터 준비 상태

`src/data/regionLootSample.ts`에는 사용자가 [12.0 패치 노트](https://playeternalreturn.com/posts/news/3743?hl=ko-KR)에서 옮긴 20개 지역, 362개 상자 획득 항목을 고정 샘플로 보관합니다. 공개 원문의 지역 표와 이름·수량을 대조했으며 식품·회복 아이템은 제외했습니다. 수량은 **지역 전체 배치량**이고 현재 패치 수치, 상자별 수량 또는 한 플레이어가 얻을 수 있는 양이 아닙니다. 현장 채집 규칙과 시작 장비 대응표는 별도 데이터 파일에 있으며, 숙련 플레이어가 제공한 요구사항으로 표시합니다.

지정된 나무위키 장비 문서 7개의 본문에서 일반~영웅 장비 153개와 직접 제작 단계를 수집했습니다. [재료 문서](https://namu.wiki/w/이터널%20리턴/아이템/재료)에서는 범위에 해당하는 재료 51개와 직접 제작 단계 18개를 추가했습니다. 현재 장비 직접 제작법은 135개이며, 이 중 `소수`와 `컴포지트 보우`는 플레이어의 **실제 게임 내 확인** 결과를 우선 적용했습니다. 각 제작법의 `outputQuantity`는 한 번 제작할 때의 결과 수량입니다. 장비 능력치는 보이는 원문 표기만 보관합니다.

재료 참조 18종은 모두 연결됐습니다. 영웅 장비 84개는 모두 일반 아이템 4개로 전개됩니다. 나무위키의 `소수 = 회단 장갑 + 유리 조각`은 구버전 정보이므로 게임 내 확인값인 `글러브 + 유리 조각`으로 수정했습니다. 나무위키 `컴포지트 보우` 항목에는 목궁 제작 트리가 잘못 표시되어 있어 게임 내 확인값인 `목궁 + 못`을 기록했습니다. 두 불일치는 제작법 데이터에도 남겼습니다. 장비 이름·등급과 제작법은 현재 화면의 재료 계산에 연결됐지만, 지역별 충당 계산은 아직 없습니다.

상자·드론 획득량은 일반 재료 1개, 고철 2개이며 직접 채집·드론 획득량은 채집 재료 2개라는 플레이어 제공 규칙을 적용합니다. 제작 결과 수량과 획득 수량은 별도로 처리합니다. 꽃 출현 지역도 플레이어 제공 규칙을 경로 판정에 사용하며, 현재 패치 공식 자료로 독립 검증되지는 않았습니다.

지도 지역 버튼은 영문 참고 지도와 웹페이지 지도 지형을 비교해 수동 추정한 중심 좌표를 사용합니다. 경로 추천에는 지역별 배치 수량이나 실제 이동 시간을 반영하지 않습니다. Eternal Return 및 관련 게임 자산의 권리는 님블뉴런 등 해당 권리자에게 있습니다. 본 앱은 비공식·비상업적 대학 과제이며 공식 제휴·승인 서비스가 아닙니다.
