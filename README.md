# ER-route-assistant

## 프로젝트 소개

《이터널 리턴》에서 영웅 장비 제작에 필요한 재료와 방문 지역을 살펴보는 웹앱입니다. 제작 경로가 낯선 플레이어는 목표 장비의 재료를 확인하고, 기존 플레이어는 지역을 바꾸며 제작 가능한 장비를 찾을 수 있습니다. **비공식·비상업적 팬 프로젝트**이며 게임 운영사와 제휴하거나 승인을 받은 서비스가 아닙니다.

## 주요 기능

- 가상 실험체 A/B와 지원 무기 유형을 고르고, 영웅 장비를 무기·옷·머리·팔/장식·다리에서 선택합니다.
- 제작법을 일반 재료까지 전개해 공통 중간 제작물, 제작 결과 수량, 시작 장비를 반영한 필요량을 즉시 표시합니다.
- 선택한 장비에 대해 최대 3개 지역·드론 1회 이하의 경로를 추천합니다. 지도에서 지역을 직접 추가·제거하고 방문 순서를 볼 수도 있습니다.
- 경로에 없는 재료는 부족으로 표시합니다. 우클릭으로 드론 배송 지정량을 1개씩 조절하고, 호출당 획득량에 따라 호출 횟수를 계산합니다.
- 지도 옆에서 현재 경로로 직접 제작 가능하거나 드론 1회가 필요한 영웅 장비를 찾습니다. 후보는 장비별로 독립 평가하며, 선택하면 목표 장비와 전체 재료 계획에 반영합니다.

## 설치 및 실행

Node.js **20.19 이상 또는 22.12 이상**이 필요합니다. API 키와 환경변수는 필요하지 않습니다.

```bash
npm install
npm run dev
```

터미널에 표시된 주소(기본 `http://localhost:5173/`)를 엽니다. 실험체·무기 유형·장비를 고른 다음 추천 경로를 누르거나 지도에서 지역을 선택하세요. 부족 재료를 우클릭하면 드론 배송량이 늘고, 노란 테두리의 드론 재료를 우클릭하면 줄어듭니다.

```bash
npm run test
npm run typecheck
npm run build
```

## 데이터 출처와 적용 범위

장비 이름·등급·제작법은 공개 나무위키의 장비 문서 7개와 재료 문서를 참고해 구조화했습니다. 나무위키의 낡은 정보와 불명확한 제작법은 제작자가 게임 안에서 확인한 결과를 우선 적용하고 문서와의 차이를 기록했습니다. 영웅 장비 **84종의 개별 제작 트리**를 테스트합니다.

지역 상자 자료는 [공식 12.0 시즌 시작 패치 노트](https://playeternalreturn.com/posts/news/3743?hl=ko-KR)에서 옮긴 **20개 지역·362개 항목의 고정 샘플**입니다. 수량은 지역 전체 배치량이며 플레이어 한 명의 획득 보장량이 아닙니다. 채집 지역과 획득 단위에는 숙련 플레이어가 제공한 규칙을 적용했습니다. 이 자료들은 현재 패치의 공식 API 응답으로 검증한 실시간 데이터가 아닙니다.

## 효과적이었던 AI 활용 시도 3가지

1. **구현 규칙과 예외 조건을 구체적으로 제시:** 공통 중간 제작물의 수요, 제작 결과 수량, 시작 재고 차감을 프롬프트에 명시해 원하는 재료 계산을 구현했습니다.
2. **문제 상황과 기대 동작을 함께 제시:** 고무 2개 중 1개만 드론으로 지정하고 싶은 사례를 전달하고, 우클릭할 때마다 지정 수량을 조절하도록 개선했습니다.
3. **검증된 게임 정보를 AI에 직접 제공:** 공개 자료의 제작법 오류를 발견한 뒤 게임에서 확인한 소수·컴포지트 보우 제작법을 제공해 Codex가 데이터와 출처 기록을 수정하도록 했습니다.

## 기술적 과제와 해결 과정

1. **API 키 대기와 자료 불일치:** 실시간 연동 대신 출처가 표시된 고정 자료를 사용했습니다. 게임 내에서 확인한 제작법은 공개 문서와의 차이를 함께 기록했습니다. 패치 최신성 한계는 남아 있습니다.
2. **공유 중간 제작물·생산 수량·시작 재고:** 목표 장비의 공동 수요를 모아 필요한 제작 횟수를 계산하고 시작 장비를 필요한 경우에만 소비합니다. 누락·순환 제작법도 테스트합니다.
3. **드론 배송 전체 지정:** 처음에는 재료 하나를 지정하면 필요량 전체가 배송 대상이 됐습니다. 재료별 지정 수량으로 바꾸고 부족·드론 타일을 분리했으며, 경로와 장비 변경 시 지정량을 다시 정리합니다.

## 테스트 및 알려진 제한사항

현재 기준 `npm run test` **72개 통과**, `npm run typecheck` 통과, `npm run build` 성공을 확인했습니다. 브라우저에서는 장비 선택, 지도 경로 편집, 드론 수량·장비 탐색을 수동 확인했습니다.

실험체는 가상 A/B이며 장비 데이터의 무기 유형은 글러브·활·방망이만 지원합니다. 공식 API 실시간 연동과 패치별 자동 갱신은 없습니다. 경로는 지역의 **재료 획득 가능 여부**를 보며 실제 확보 수량, 경쟁, 이동 거리·시간, 하이퍼루프를 계산하지 않아 최적 경로를 보장하지 않습니다. 랭커 루트 추천, 최종 장비 능력치 비교, 전설 장비 교체도 구현되지 않았습니다. 게임과 지도 자산의 권리는 님블뉴런 등 해당 권리자에게 있습니다.

## 주요 소스 코드

1. `src/App.tsx` — 실험체·장비·경로·드론 상태 연결
2. `src/domain/craftingCalculator.ts` — 공유 중간 제작물과 시작 재고 계산
3. `src/domain/materialPlan.ts` — 경로 포함·부족·드론 지정 재료 관리
4. `src/domain/routeRecommendations.ts` — 방문 순서가 있는 경로 추천
5. `src/domain/craftableEquipment.ts` — 경로별 제작 가능 장비 분류
