# ER-route-assistant

Eternal Return 플레이어를 위한 루트 작성 앱의 **1단계 목 데이터 시연**입니다. 현재는 캐릭터와 지원 무기 유형을 선택하고 시작 Common 장비를 확인할 수 있습니다.

## 실행

Node.js 20.19 이상 또는 22.12 이상이 필요합니다.

```bash
npm install
npm run dev
```

검사: `npm run typecheck`, `npm run test`, `npm run build`.

## 목 데이터와 출처

화면과 데이터의 캐릭터·장비·지역·재료 수량은 **가상의 학습용 예시**이며 실제 게임 정보가 아닙니다. 무기 유형 이름, 시작 Common 무기·Shirt·Sneakers 규칙, 고철 1회 드롭의 2개 묶음은 숙련 플레이어가 제공한 프로젝트 요구사항을 바탕으로 합니다. 이를 독립적으로 검증한 공식 API 명세로 제시하지 않습니다. `mock-*` ID는 앱 내부 식별자이며 공식 API 코드가 아닙니다.

가상 지역의 인접 관계, 하이퍼루프 유무, 상자 그룹별 수량은 오직 데이터 구조 시연용입니다. 실제 지역 연결이나 아이템 생성 수량으로 해석해서는 안 됩니다. 공식 API 키 요청은 아직 처리 중입니다.

## 현재 범위와 다음 단계

`src/data/`의 비동기 저장소 인터페이스를 통해 목 카탈로그를 제공합니다. `src/domain/`에는 무기 유형, 장비·제작법·시작 재고·재료·상자 그룹·지역·루트·드론 배송 타입과 시작 장비 조회만 있습니다.

현재 제작법 목록은 비어 있습니다. 재귀 제작 계산, 재료 충당, 상자 그룹 평가, 수동 루트 평가, 빌드 A/B 비교, 공식 API 연결은 구현하지 않았습니다. 추후 API를 연결할 때는 키가 브라우저에 노출되지 않도록 별도 서버 중계를 사용해야 합니다.
