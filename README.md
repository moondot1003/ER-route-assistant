# ER-route-assistant

Eternal Return 플레이어를 위한 루트 작성 앱입니다. 현재 화면에서는 **1단계 목 데이터**로 캐릭터와 지원 무기 유형을 선택하고 시작 Common 장비를 확인할 수 있습니다. 제작법과 지역 획득 데이터는 이후 기능을 위한 별도 참조 자료로 준비했습니다.

## 실행

Node.js 20.19 이상 또는 22.12 이상이 필요합니다.

```bash
npm install
npm run dev
```

검사: `npm run typecheck`, `npm run test`, `npm run build`.

## 목 데이터와 출처

현재 화면이 사용하는 목 카탈로그의 캐릭터·장비·지역·재료 수량은 **가상의 학습용 예시**이며 실제 게임 정보가 아닙니다. 무기 유형 이름과 시작 Common 무기·Shirt·Sneakers 규칙은 숙련 플레이어가 제공한 프로젝트 요구사항을 바탕으로 합니다. 목 카탈로그의 고철 묶음 수치도 시연용이며 별도 지역 자료의 수량 계산에는 적용하지 않습니다. 이를 독립적으로 검증한 공식 API 명세로 제시하지 않습니다. `mock-*` ID는 앱 내부 식별자이며 공식 API 코드가 아닙니다.

가상 지역의 인접 관계, 하이퍼루프 유무, 상자 그룹별 수량은 오직 데이터 구조 시연용입니다. 실제 지역 연결이나 아이템 생성 수량으로 해석해서는 안 됩니다. 공식 API 키 요청은 아직 처리 중입니다.

## 현재 범위와 다음 단계

**구현됨:** `src/data/`의 비동기 저장소 인터페이스를 통해 화면용 목 카탈로그를 제공하고, 캐릭터·지원 무기 유형 선택과 시작 Common 장비 표시를 지원합니다. `src/domain/`에는 무기 유형, 장비·제작법·시작 재고·재료·상자 그룹·지역·루트·드론 배송 타입과 시작 장비 조회가 있습니다. 별도의 장비·재료 제작법, 시작 장비 대응표, 지역 획득 자료와 이를 검증하는 테스트도 준비했습니다.

**미구현:** 화면용 목 카탈로그의 제작법 목록은 비어 있고, 준비한 참조 자료도 아직 화면에 연결되지 않았습니다. 영웅 장비 선택 UI, 사용자용 재귀 제작 계산, 시작 장비 차감, 재료 충당, 상자 그룹 평가, 수동 루트 평가·추천, 빌드 A/B 비교, 공식 API 연결은 구현하지 않았습니다. 추후 API를 연결할 때는 키가 브라우저에 노출되지 않도록 별도 서버 중계를 사용해야 합니다.

## Phase 2·3 데이터 준비 상태

`src/data/regionLootSample.ts`에는 사용자가 [12.0 패치 노트](https://playeternalreturn.com/posts/news/3743?hl=ko-KR)에서 옮긴 20개 지역, 362개 상자 획득 항목을 고정 샘플로 보관합니다. 공개 원문의 지역 표와 이름·수량을 대조했으며 식품·회복 아이템은 제외했습니다. 수량은 **지역 전체 배치량**이고 현재 패치 수치, 상자별 수량 또는 한 플레이어가 얻을 수 있는 양이 아닙니다. 현장 채집 규칙과 시작 장비 대응표는 별도 데이터 파일에 있으며, 숙련 플레이어가 제공한 요구사항으로 표시합니다.

지정된 나무위키 장비 문서 7개의 본문에서 일반~영웅 장비 153개와 직접 제작 단계를 수집했습니다. [재료 문서](https://namu.wiki/w/이터널%20리턴/아이템/재료)에서는 범위에 해당하는 재료 51개와 직접 제작 단계 18개를 추가했습니다. 현재 장비 직접 제작법은 135개이며, 이 중 `소수`와 `컴포지트 보우`는 플레이어의 **실제 게임 내 확인** 결과를 우선 적용했습니다. 각 제작법의 `outputQuantity`는 한 번 제작할 때의 결과 수량입니다. 장비 능력치는 보이는 원문 표기만 보관합니다.

재료 참조 18종은 모두 연결됐습니다. 영웅 장비 84개는 모두 일반 아이템 4개로 전개됩니다. 나무위키의 `소수 = 회단 장갑 + 유리 조각`은 구버전 정보이므로 게임 내 확인값인 `글러브 + 유리 조각`으로 수정했습니다. 나무위키 `컴포지트 보우` 항목에는 목궁 제작 트리가 잘못 표시되어 있어 게임 내 확인값인 `목궁 + 못`을 기록했습니다. 두 불일치는 제작법 데이터에도 남겼습니다. 이 데이터는 현재 화면이나 사용자용 계산에 연결되지 않았습니다.
